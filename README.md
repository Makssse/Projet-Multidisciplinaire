# Projet-Multidisciplinaire
Nous sommes des étudiants en Génie Physique à l'INSA Toulouse et travaillons sur un projet de réseau de capteurs C02 pour des bâtiments publics (écoles, mairies...). Nous avons crée ce GitHub dans le but de rendre ce projet accessible à tous.tes, notamment aux non-intié.e.s qui souhaiteraient l'implémenter dans leurs locaux.

Vous pouvez y trouver : 
- le "Guide de fabrication" qui est un manuel de construction contenant tous les détails nécessaires à la fabrication des capteurs et à la mise en place du réseau. Ce manuel indique dans chaque section quand se servir des autres ressources du Github.
- le dossier "Home Assistant" qui contient tout les codes nécessaire à la création de l'interface utilisateur.
- le dossier "src" qui contient tout le code python et notament :
    - les codes à implémenter sur les pi pico (dossiers "code salle x")
    - le code pour tester son réseau ethernet dans le dossier "test_ethernet" (le protocole de test est disponible dans la section test ethernet du manuel de fabrication)
    - les codes de test pour chaque composante et capteurs dans le dossier "code test"
    - les autres code qui nous ont été utile dans le dossier "autre code"
- le dossier initialisation RP Pico qui contient le fichier d'initialisation de la Pi Pico. Vous trouverez le protocole dans le guide d'utilisation.
- le dossier "impression 3D" ou vous trouverez tous les fichiers nécessaire à l'impression de la coque 3D dans un fablab, les fichiers à imprimés étant dans le dossier "fichiers pour impression" : "LOUTRE_CREUSEE_VF" et  "LOUTRE_VENTRE_VF".
